## 🌟 Key Features

1. **Multi-Page Architecture**
   - **Home (`index.html`):** Hero consultation intro, verified Google review highlights, quick information cards, clinical overview.
   - **About Us (`about.html`):** Hospital philosophy, core pillars of care, emergency readiness, and verified Google profile card.
   - **Services (`services.html`):** Department directory (Emergency 24/7, General Medicine, Pediatrics, Diagnostic Lab, Preventive Health, Pharmacy).
   - **Our Team (`team.html`):** Verified physician profiles with credentials, specialties, and explicit consultation timings.
   - **Gallery (`gallery.html`):** Interactive clinical facility gallery with category filters (Consultation Suites, Diagnostics & Lab, Reception & Inpatient).
   - **Blog (`blog.html`):** Health insights articles with category tags, read times, and physician bylines.
   - **Contact Us (`contact.html`):** Interactive appointment booking, live Google Map directions, commute time estimation, and contact details.

2. **Smooth Medical-Grade Motion & Animations**
   - **Keyframe Floating Badges:** Floating 24/7 emergency care and 4.6★ Google rating badges.
   - **Beacon Status Indicator:** Real-time pulsing green beacon wave indicating 24/7 hospital readiness.
   - **Scroll Reveal System:** Cascading entrances with `IntersectionObserver` across all sections and cards.
   - **Animated Stat Counters:** Smooth count-up animations for rating (4.6★) and reviews (15).
   - **Accessible Reduced Motion:** Full `@media (prefers-reduced-motion: reduce)` compliance.

3. **Patient Mobile Experience**
   - **Sticky Action Bar:** Direct one-tap access on smartphones for **Call**, **Directions**, **Appointment**, and **WhatsApp**.
   - **Large Touch Targets:** Minimum 44px touch targets on buttons, clear form labels, and high contrast.

4. **Strict Booking Integrity**
   - Form validation with date constraints (no past dates).
   - Honest booking notice explaining that appointments are verified by the hospital front desk before finalization.

## 🚀 How to Run Locally

This website requires **no build tools or external dependencies**.

### Quick Start:
Double-click `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### With Built-in HTTP Server:
Run the included PowerShell server:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Then visit `http://localhost:8080/` in your browser.
